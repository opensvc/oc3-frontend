# Graphic assets

- `opensvc-logo.svg`: OpenSVC logo, taken from
  `https://www.opensvc.com/assets/images/favicons/favicon.svg`. Used in the top bar and
  on the sign-in screen.
- `public/favicon.ico` (at the repository root): the same logo, rasterized at 16, 32 and
  48 px and assembled into an ICO with PNG entries. Regenerate it from the SVG if the
  logo changes.
- `os/`: operating system logos, see `os/README.md`.
