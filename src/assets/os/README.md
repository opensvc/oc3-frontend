# Operating system logos

Taken as-is from the historical collector (`init/static/images/` in the
`opensvc/collector` repository, Apache 2.0 license), where they decorate node names
(`.os_*` in `init/static/css/base.css`).

The logos remain the property of their respective owners; they are used here solely to
identify a node's operating system. Tux was created by Larry Ewing with The GIMP.
